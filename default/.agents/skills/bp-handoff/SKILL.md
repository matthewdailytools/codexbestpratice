# 交付与续接

核对用户原始目标、接受的调整与实际工作区状态。交付先说明结果，再给出实际测试结果、重要限制、文件入口和必要的使用步骤。

长任务中断或转交时，按需使用 `.codex-bp/templates/handoff.md`，记录目标、决策、已完成项、当前状态、验证、剩余工作与恢复入口。文字记录默认 Markdown、当前工作目录保存。

存在 goals/ 与 plans/ 时链接当前里程碑的目标和计划，分别核对目标验收与任务进度；沿用已有记录来源。进入下一里程碑时建立新记录并链接前置结果，不覆盖已完成里程碑或另建冲突状态。

涉及发布时交代适用的版本、迁移、监控与回滚准备；这些准备不代表已经发布。恢复任务前核对当前代码和文件状态，避免把历史记录当作仍然成立的事实。

未完成的必要工作不能标成完成；不要以交接代替仍可继续执行的授权任务。提交、推送与部署遵循本次用户授权，不从本技能推导新权限。
