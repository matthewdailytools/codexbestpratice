# macOS 桌面 UI 与交互

核实最低 macOS 版本、既有 AppKit／SwiftUI／跨平台工程与应用形态。尊重 Mac 用户的菜单、窗口和文档习惯；支持能力按产品实际系统版本核实，不强制采用最新视觉效果或增加签名权限。

- 设计适合桌面任务的信息密度、侧栏、工具栏和内容层级，统一语义颜色、字体与间距，复用系统组件或现有设计系统。允许合理调整窗口大小，不把所有任务塞进固定尺寸的移动界面。
- 重要命令在菜单栏或清楚入口可发现，遵循 Command 快捷键与平台编辑习惯；键盘、鼠标和触控板均能完成核心任务，右键、悬停或手势不是唯一操作路径。
- 区分关闭窗口、退出应用与关闭文档；产品需要时处理多窗口、当前文档与保存状态。文档编辑明确撤销、自动／显式保存、未保存退出和冲突恢复，不套用浏览器或 Windows 的退出假设。
- 适配窗口缩放、显示器、深浅主题、系统文字与减少动态效果，保留可见焦点和 VoiceOver 的名称、角色、状态及阅读顺序。支持目标硬件的其他输入时提供合适命中区域，不以桌面为由排除辅助输入。
- 处理加载、空内容、错误、离线、进度和取消；耗时 I/O 不阻塞界面。文件访问、权限与沙盒能力采用当前工程已有入口，未授权时说明可恢复路径。
- 验证菜单和快捷键、键盘导航、焦点恢复、窗口缩放、适用的多窗口／文档状态与 VoiceOver。未在 macOS 构建或运行时明确说明，不以 Windows 上的静态审查冒充原生验收。

依据：[Apple macOS HIG](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos)、[Apple 布局](https://developer.apple.com/design/human-interface-guidelines/layout)。
