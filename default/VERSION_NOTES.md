# 默认规范 1.0 · 版本说明

日期：2026-11-13。参考用户提供的《2026 年 ChatGPT Codex 最佳项目开发实践》，将其工程要求整理为可复制文件包。

## 使用

将本文件夹内的全部内容（包括 `.agents/` 和 `.codex-bp/`）复制到 Codex 项目根目录。已有同名文件时先比较并合并，特别是已有 AGENTS.md、技能和项目配置，保留原约定。

打开项目的新 Codex 运行。先让 agent 检查项目用途、技术栈与实际验证入口，逐步补齐 `.codex-bp/project.json`；配置中的待填写项、空列表和 confirmed 状态不代表业务已明确或测试已通过。

工作台中的默认原件只读。需要维护自己的规范时选择“新建一套”，在整套副本中修改、保存并导出；默认原件保留。

## 文件组成

- `AGENTS.md`：持续适用的精简入口，以及按任务读取的章节索引。
- `.codex-bp/rules/`：按参考文章顺序排列的 14 章规则。
- `.agents/skills/`：6 个流程技能与 7 个平台／后端专项技能，按需读取。
- `.codex-bp/prompts/`：12 份可复制的任务 Prompt，覆盖完整任务、项目分析、八阶段、续接与复盘。
- `.codex-bp/templates/`：需求、目标、计划、验证、评审、交接的记录模板。
- `.codex-bp/project.json`：待补齐的项目事实与验证入口。
- `.codex-bp/manifest.json`：完整文件清单、导航与默认原件哈希，供浏览界面和导出使用。
- `VERSION_NOTES.md`：复制说明、设计取舍与验证边界，不承载隐藏的执行规则。

## 与参考文章的关系

导航依次为：整体工作流、项目初始化、需求分析、任务拆分、统一任务执行、测试策略、多 Agent、Git、安全与权限、Skills/MCP/自动化、日常节奏、常见错误、工程配置、项目类型。

保留原文的工程闭环，示例不强制套用：小任务不走完整项目仪式；检查按实际风险与现有入口选择；不预建数据库、认证或固定分层；多 Agent、外部集成和发布依据任务授权。已有 GOALS.md、PLANS.md 等状态来源继续沿用。

规则正文、技能和模板可在导航直接阅读；背景解释与使用说明统一展示在本版本说明，不再维护一套平行的阶段说明。

## 能力与验证边界

复制文件提供项目指引和可发现技能，不会安装语言环境、依赖、MCP、CI 或修改全局 Codex 配置。规范不构成生产操作授权，也不能保证所有模型每次都遵循。

静态完整性、界面读写、新项目实际加载与真实模型表现分别验证；具体结果见工作台项目的交付验证记录。此前旧包的行为成绩不能自动视为本包的结果。

## Prompt 模板

按原文项目分析、任务规划、编码实现和代码审查的结构，补齐需求、架构、初始化、验证、交付、续接与复盘；另提供完整任务入口。每份明确输入、执行要求、输出和验收边界。单阶段模板只处理选定阶段；需要持续完成整个目标时使用完整任务模板。

在第五章展开对应模板可阅读与复制 Prompt；需要调整时先新建整套副本。Prompt 用于发起任务，templates/ 用于记录任务产物，二者分别维护。
