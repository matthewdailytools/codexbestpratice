# 需求分析 Prompt

请先将以下目标整理为可实现、可验收的需求，本轮不写业务代码。

## 输入

- 目标：[填写要解决的问题]
- 用户与场景：[填写已知内容]
- 现有资料：[填写或由当前项目读取]
- 限制与期望：[填写范围、兼容、时间或运行约束]

## 执行要求

1. 阅读项目规则、已有需求、相关实现及任务记录，区分已有功能与目标能力。
2. 分别梳理产品、功能、技术和验收需求，描述主要流程、状态、错误与边界。
3. 识别角色、权限、数据和非功能要求；不自动增加登录、支付、数据库等未要求能力。
4. 对无法从环境获取且影响方案的关键业务规则集中提问，说明影响；未回答继续保留未决，不把建议当作决策。
5. 已有信息直接引用，不重复索要。明确原型授权时说明假设和模拟边界。

## 输出与验收

目标、用户、范围内外、功能与非功能需求、业务规则、未决问题、逐项验收场景。复杂需求按需保存需求说明模板；已有记录继续使用。
