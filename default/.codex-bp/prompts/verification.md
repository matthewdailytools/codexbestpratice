# 自动化验证 Prompt

请对以下任务或变更完成与风险相称的验证。

## 输入与边界

- 验证对象：[目标、提交／工作区差异或具体功能]
- 验收：[填写或引用]
- 环境与依赖：[填写已知内容，其他从项目核实]
- 修复授权：[默认仅验证并报告；如允许修复请明确填写]

## 执行要求

1. 读取项目规则、差异、相关实现、调用方、测试脚本和 CI，确认真实检查入口。
2. 按影响选择单元、回归、集成、API／契约、E2E、安全或性能检查；适用时运行现有 Lint、类型和构建入口。
3. 覆盖正常、失败、边界、兼容及相关权限路径。缺陷优先最小复现；真实依赖不可用时明确阻塞，不能把模拟当真实集成。
4. 实际执行并查看退出码、发现数量和结果。零测试不能当通过，配置中 confirmed 也不能当执行证据。
5. 失败后定位原因；在允许的修复范围内修复并复验，否则保存问题及重跑方式，不修改探针或降低标准。

## 输出与验收

验证范围与环境、实际命令、检查数量、通过／失败／未运行／未配置、缺陷证据、限制及下一步。需要保存时使用验证记录模板。
