# 任务拆分 Prompt

请将已明确的需求和方案拆成可执行计划，本轮只规划，不写业务代码。

## 输入

- 需求与验收：[填写或引用]
- 已选技术方案：[填写或引用]
- 本轮范围：[填写]
- 已有计划来源：[已有记录优先；没有则按项目规范选择]

## 执行要求

1. 阅读项目规则、相关代码和已有任务状态，先核实前置工作是否真实完成。
2. 根据业务依赖划分可独立验收的里程碑，不强制固定数据库、认证或前端阶段。
3. 每项任务写明目标、涉及文件／模块、范围外事项、前置依赖、实现步骤、交付物和验收。
4. 明确接口与数据兼容、失败路径、验证入口和重要风险；待决规则保持未决。
5. 复用现有 PLANS、Issue 或其他状态来源；新多里程碑按需创建同名互链 goals/ 与 plans/。
6. 并行分工只有在获授权且确有收益时采用，先定义契约、文件归属与集成责任。

## 输出与验收

需求理解、方案引用、任务与依赖、验证计划、风险、当前状态和续接入口。计划中的“待执行”不能写成已验证完成。
