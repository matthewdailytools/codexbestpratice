# 续接与交接 Prompt

请根据当前项目记录继续任务，以实际代码为准完成已授权的剩余工作。

## 输入

- 交接／计划来源：[填写已有记录路径]
- 本轮目标与授权：[填写]
- 新增约束或决定：[填写，没有则留明“无”]

## 执行要求

1. 阅读 AGENTS.md、交接、相关目标／计划、工作区状态和实际实现，核对历史“已完成”是否仍成立。
2. 发现过期记录时依据已接受需求和代码纠正，保留用户改动和既有任务来源。
3. 按依赖完成本轮授权内的必要任务，运行实际验证；关键业务未知继续标记待决，不用猜测补全。
4. 维护准确的目标、进度和证据，未验证的里程碑不能标成达成。
5. 交接记录包含目标、决定、已完成、当前状态、真实验证、剩余任务和恢复入口，区分必要未完成、可选建议与外部阻塞。

## 输出与验收

给出当前结果、纠正的历史偏差、实际验证和更新记录入口。仍可执行的必要工作不要用交接说明替代。
