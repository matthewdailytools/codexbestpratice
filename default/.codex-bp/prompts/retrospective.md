# 复盘与规范改进 Prompt

请针对以下实际问题复盘，提出可复用且范围明确的改进。

## 输入与边界

- 问题与证据：[填写真实错误、重复现象、记录或复现路径]
- 期望行为：[填写]
- 本轮授权：[默认分析和建议；若需维护规范，先在工作台新建整套副本]

## 执行要求

1. 核实实际发生的行为、输入、规则、执行环境和结果，区分事实与推断。
2. 定位原因在需求、项目事实、规则触发、实现、验证还是工具环境，不将一次网络故障直接归因于模型不遵循。
3. 检查现有规则或技能能否解决；避免增加重复约束、扩大权限或把所有小任务变成完整流程。
4. 说明拟改内容、触发范围、与现有约定的关系，以及可观察的验证案例。
5. 默认原件保持只读。获得维护授权后在另建整套副本中修改，真实验证后分别报告成功、失败和未覆盖项。

## 输出与验收

事实与证据、原因、改进建议、适用边界、验证方法和剩余不确定性。不能用主观感受或自称通过代替行为证据。
