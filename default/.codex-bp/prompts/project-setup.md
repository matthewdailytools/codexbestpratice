# 项目初始化 Prompt

请准备当前目标需要的最小可运行、可验证工程环境。

## 输入

- 项目目标：[填写]
- 已接受方案：[填写或引用]
- 初始化范围：[新项目骨架／已有项目环境检查，选择并填写]
- 技术与运行约束：[填写]

## 执行要求

1. 阅读项目入口、工作区和现有工程清单，复用已有文件、运行环境和工具链。
2. 默认规范已在项目中时只核对引用、配置和相关技能，不重复安装远程工作台。
3. 新项目按目标建立最小适用结构；已有项目保留原布局，不为示例搬动源码或覆盖同名文件。
4. 核实启动、测试和适用构建命令，更新已知项目事实；未知检查保持待补齐。必要依赖按当前授权准备，不改全局 Codex 配置。
5. 提供不含真实秘密的必要配置示例与运行说明；没有需求不预建认证、数据库、云服务或 CI。
6. 实际启动或运行可用的最小验证，检查发现数量与结果，报告环境阻塞。

## 输出与验收

实际准备的文件和环境、项目入口、已执行命令与结果、仍需配置项和下一步。文件存在、可运行、技能发现和业务通过分别说明。
