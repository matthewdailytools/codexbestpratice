# 交付与发布准备 Prompt

请核对以下任务并完成当前授权范围内的交付。

## 输入

- 原始目标与已接受调整：[填写或引用]
- 验收：[填写或引用]
- 交付对象／入口：[填写]
- 发布授权：[默认仅本地交付；提交、推送或部署需明确填写]

## 执行要求

1. 核对当前代码、工作区、计划和实际 diff，对照验收逐项确认，不仅依据历史“完成”记录。
2. 检查必要说明、配置和运行入口，确保没有未说明的必需占位功能或未完成项。
3. 复核真实验证证据，区分通过、失败、未运行和环境限制；适用且必要的未完成工作继续执行。
4. 涉及数据或发布时说明实际需要的兼容、迁移、监控和恢复准备；材料存在不代表已经发布。
5. 提交、推送、生产部署、外部消息与真实数据操作仅在实际授权内执行，保留用户已有修改。

## 输出与验收

先给完成结果和可用入口，再说明变更、实际测试、使用步骤、未完成项与限制。明确区分本地完成、已提交、已发布和已上线。
