# 十、Skills、MCP 与自动化

## Skills

按任务选择相关技能，先明确用途、输入、产物和验收。UI 由实际交付平台决定；后端任务读取后端技能，纯静态页面不强制引入服务。不要一次加载所有平台正文。

技能不能替代项目事实，也不构成新授权。现有规则足以覆盖的问题不再创建重复技能；实际重复问题或明确用户要求才沉淀新流程。

## MCP 与外部能力

有适用连接器时优先用其完成已授权操作；缺少能力再选择其他方式。只接入真实任务需要的系统，不把复制规范包说成 MCP、外部账号或权限已经配置。

## 自动化

先手动验证稳定流程，再根据用户明确的自动化或定期要求建立调度。技能定义方法，调度定义时间；不能仅凭工程规范自动创建定时任务、子代理或无人监督发布。
