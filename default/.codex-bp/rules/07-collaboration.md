# 七、多 Agent 协作

只有用户或适用项目约定明确授权分工，且任务确有独立并行收益时，才创建子代理。单代理任务照常规划、实现、验证和自查，不为了模仿团队增加代理。

## 分工前

主代理明确目标、接口和数据契约、文件归属、范围外事项、依赖及验收。避免多个代理同时修改相同核心文件、公共模型和路由。

## 工作隔离

按宿主能力使用独立工作区或已授权的 worktree；沿用用户选择，不因技能自动建立新会话、发送消息、提交或推送。并行数量、模型和权限遵循宿主及任务要求。

## 集成责任

主代理审阅产物、解决契约和冲突、核对整体 diff 并执行集成验证。子任务通过不等于整体通过，代理自称完成不代替证据。只有确实由不同执行者完成的审查才能称为独立评审。
